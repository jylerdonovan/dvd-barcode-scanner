DVD Packing Mode

Use this for DVDs already imported into your DVDs sheet. Scan a UPC, choose the exact copy, and assign its storage location. Existing inventory IDs are not changed.

1. Load inventory

2. Find the disc

3. Choose location

Use the same box number until it's full. Start the next number when you open a new box. The system assigns the next storage ID automatically.

Important: If the UPC is not found, scan it using your existing New DVD scanner and import it through DVD Tools first. Then reload this packing page. Do not tap Save twice if a request is still being verified.
